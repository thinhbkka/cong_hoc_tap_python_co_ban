# Cổng Học Tập Python Cơ Bản

## 📚 Giới thiệu

**Cổng Học Tập Python Cơ Bản** là website học tập được xây dựng bằng **Docsify**, cung cấp nội dung nhập môn Python theo lộ trình từ cơ bản đến thực hành.

Website hướng đến người mới bắt đầu học lập trình, giúp người học từng bước làm quen với Python, nắm các khái niệm nền tảng và áp dụng kiến thức thông qua bài tập.

## 🎯 Mục tiêu

Sau khi hoàn thành nội dung khóa học, người học có thể:

- Hiểu những khái niệm cơ bản của Python.
- Làm việc với biến và các kiểu dữ liệu cơ bản.
- Sử dụng cấu trúc điều kiện.
- Sử dụng vòng lặp.
- Xây dựng và sử dụng các hàm đơn giản.
- Vận dụng kiến thức để giải quyết các bài tập Python cơ bản.

## 🗂️ Nội dung khóa học

### Kiến thức Python

1. **Làm quen với Python**
2. **Biến và kiểu dữ liệu**
3. **Cấu trúc điều kiện**
4. **Vòng lặp**
5. **Hàm**

- Kiểm tra kiến thức Python cơ bản.
- Câu hỏi trắc nghiệm.
- Dự đoán kết quả chương trình.
- Bài tập viết chương trình.

## 🔌 Plugin

Website sử dụng một số plugin Docsify để tăng tính tiện dụng:

- **Search** – tìm kiếm nội dung.
- **Copy Code** – sao chép mã nguồn.
- **Count** – hiển thị số từ và thời gian đọc.
- **Dark / Light Theme** – chuyển đổi giao diện sáng và tối.

## 🚀 Cách sử dụng

Người học có thể truy cập website và học theo thứ tự:

**Làm quen với Python → Biến và kiểu dữ liệu → Cấu trúc điều kiện → Vòng lặp → Hàm**

Sau mỗi phần kiến thức, người học nên thực hiện các bài tập để củng cố nội dung đã học.
